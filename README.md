# ⚔ JEON SE JIN · Minecraft Portfolio

마인크래프트 스타일로 만든 개인 포트폴리오 페이지입니다.
순수 HTML/CSS/JavaScript 한 파일로 동작하며, 빌드 도구나 외부 라이브러리가 없습니다.

## ✨ 주요 기능

- **Canvas 픽셀 배경** — 하늘·구름·산·나무·땅을 실시간으로 그립니다
- **몹 애니메이션** — 크리퍼, 좀비, 스켈레톤, 거미, 엔더맨, 스티브, 돼지가 걸어다닙니다
- **파티클 시스템** — 탭마다 다른 효과 (폭발 / 경험치 / 마법부여 / 불꽃 / 하트 / 물약)
- **업적 토스트** — 탭을 누르면 Achievement Unlocked 알림
- **로딩 스크린** — 월드 생성 진행바
- **반응형 레이아웃** — 모바일 지원
