    산정 방법
    • 지역 지정 — 검색·지도 클릭은 Nominatim(OSM) 행정 경계 폴리곤을, 직접 그리기는 그린 다각형을 분석 영역으로 씁니다.
    • 아파트 — Overpass로 영역 범위의 building=apartments 건물을 받아 영역 폴리곤 안의 것만 남깁니다. 연면적 추정은 바닥면적 × building:levels(없으면 설정의 기본 층수)입니다.
    • 지역대비 밀도(LQ) — 영역을 육각 격자로 나누고, 격자 밀도(가우시안 커널 평활화 선택)를 지역 평균 밀도(전체 아파트 ÷ 영역 면적)로 나눕니다. LQ 2는 평균의 두 배입니다.
    • CBD 선정 — LQ가 임계값 이상인 격자 중 맞닿은 것끼리 군집으로 묶고, 아파트 규모(밀도×면적 합)가 가장 큰 군집을 CBD, 그다음 군집을 부도심으로 표시합니다. 임계값을 넘는 격자가 없으면 상위 3% 격자로 대신합니다.
    • SGIS(선택) — 행정동 경계(UTM-K → WGS84 변환)와 주택총조사 아파트 수(stats/house.json)로 행정동별 LQ를 계산해 OSM 결과와 평균합니다.

    여기서 CBD는 전통적인 업무 중심지가 아니라 아파트가 지역 평균보다 두드러지게 밀집한 핵심 권역을 뜻합니다. OSM 건물 입력이 부족한 지역은 결과가 치우칠 수 있으니 SGIS 통계와 함께 보세요.

    SGIS API 설정

    SGIS 개발지원센터(sgis.mods.go.kr)에서 발급받은 서비스 ID와 보안 Key를 입력하세요. 값은 이 브라우저의 localStorage에만 저장되고 SGIS API 호출에만 쓰입니다.
